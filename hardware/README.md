# hardware —— 硬件资料

自制板卡与整车的原理图、PCB 源文件、机械图纸。按「一块板一个目录」组织，
目录名与四端角色对应：

| 目录 | 内容 |
| --- | --- |
| `drive-board/` | 电驱板（STM32G431RBT6 + DRV8301 ×2 + MT6816 ×2） |
| `control-board/` | 下位机主板（ESP32-S3 + CAN 收发器） |
| `power-board/` | 电源板（母线 → 5V/5A、3.3V、12V 舵机三路） |
| `remote-board/` | 遥控器（现成硬件）：参考原理图 |
| `mechanical/` | 整车机械：飞轮、轴承座、支撑杆、摩擦传动压紧机构 |

## 电驱板图纸

`drive-board/` 下是电驱板组的两块板、四张导出图。驱动板（Schematic1）与
主控板（Schematic2）是两块独立板，经 H1/H2 两个 20pin 排针互连：

| 文件 | 内容 |
| --- | --- |
| `DRV1.png` | 驱动板第 1 页 DRIVE1：DRV8301-1、三相桥（NCE6045G ×6）、内部 Buck 5V |
| `DRV2.png` | 驱动板第 2 页 DRIVE2：DRV8301-2、三相桥、内部 Buck |
| `接口部分.png` | 驱动板第 3 页：电源入口、母线电容、泄放回路、母线电压采样、H1/H2 排针 |
| `STM32.png` | 主控板 P1：STM32G431RBT6、CAN 收发器、编码器接口、H1/H2/H3 排针 |
