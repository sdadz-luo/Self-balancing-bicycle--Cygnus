# hardware —— 硬件资料

自制板卡与整车的原理图、PCB 源文件、机械图纸。按「一块板一个目录」组织，
目录名与四端角色对应：

| 目录 | 内容 |
| --- | --- |
| `drive-board/` | 电驱板（STM32G431RBT6 + DRV8301 ×2 + MT6816 ×2） |
| `control-board/` | 下位机主板（ESP32-S3 + CAN 收发器） |
| `power-board/` | 电源板（母线 → 5V/5A、3.3V、12V 舵机三路） |
| `remote-board/` | 遥控器（现成硬件）：参考原理图 |
| `mechanical/` | 整车机械：飞轮、轴承座、支撑杆、摩擦传动压紧机构 |

入库原则：**EDA 源工程与导出的 PDF 图纸入库**（可追溯、可查看），
**整个工程目录一起放**——缺库文件图纸打不开；**Gerber、BOM、3D 导出等
生产文件不入库**（随用随导出，需要追溯打样版本时再单独归档）。
