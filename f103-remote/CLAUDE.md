# f103-remote —— 遥控器（STM32F103C8T6）工作约定

按需上电的手动控制手段，**不纳入安全设计**（可作为急停触发源，但不是安全
链的一环）。硬件沿用江协科技平衡车套件：STM32F103C8T6 + 板载 NRF24L01P +
AT2401C 功放。**硬件沿用、固件自研**，尚未开工。

## 构建

Keil MDK5，布局同 [g431-drive](../g431-drive/)。

## 改动禁区

- **射频参数任一项都必须两端一致**——速率（建议 250 kbps）、频道（`RF_CH` 60 ~ 70）、
  地址、CRC / 地址宽度、载荷宽度、自动应答与重传；改一端等于断链
- **遥控帧格式改动必须两端同步**（32 字节前 7 字节逐字节：`[0]` Mode、`[1]~[4]`
  LH / LV / RH / RV（-100~100）、`[5]` KEY0（K1~K8 位图）、`[6]` KEY1（K9~K12 位图））
- **急停键位接口预留**：遥控器是急停发起源之一（具体键位 / 协议待定，见技术方案
  「待定事项」）；「收到急停键 → 立即发 CAN 0x001」的动作在 ESP32 侧做
- 遥控距离的短板在车端（普通模块回发的 ACK 太弱、PA 端收不到，重传耗尽后
  链路失败）——调试链路问题时先怀疑车端
