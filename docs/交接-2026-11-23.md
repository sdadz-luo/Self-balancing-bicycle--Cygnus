## 二、关键决策与依据

- **CTRL1 = 0x790**：OC_ADJ_SET=30（VDS 2.131 V）、OCP 锁存关断、6-PWM、
  GATE_CURRENT = 1.7 A
- **CTRL1 位布局（实测确认）**：OC_ADJ_SET = D10:D6、OCP_MODE = D5:D4、
  PWM_MODE = D3、GATE_RESET = D2、GATE_CURRENT = D1:D0
- **OC_ADJ_SET = 30 的依据**：NCE6045G RDS(on) ≈ 10 mΩ@25°C（用户口径），
  高温按 1.5 倍取 15 mΩ，跳闸目标 150 A → 2.25 V，Table 13 就近取码 30
  （高温约 142 A、25°C 约 213 A）。**台架阶段 3 逐级升流实测校正**
- **DRV SPI 时钟 /64 = 2.66 MHz**：手册 t_CLK ≥ 100 ns（上限 10 MHz），取保守档
- **读回校验失败 → 重试 3 次 → 停机闪灯**
- **CTRL2 保持 0**（默认值）：位布局未实测，改 GAIN/OCTW_MODE/DC_CAL 前
  先用「写 1 读回」法验证位位置，勿按 PDF 列标注直接写

## 三、已踩的坑（勿重复）

1. **TI SLOS719F PDF 的 Table 11 位列标注与芯片实际不符**——已存记忆
   `drv8301-register-bit-layout`，代码注释亦写明。判据：写 0x03E 读回 0x03A，
   差异位 D2 是 GATE_RESET 写 1 自清的行为
2. **HAL_SPI_TransmitReceive 在 Size>1 时按 uint16 访问缓冲区**（对齐与字节序
   依赖实现细节），所以 `spi.c` 拆成两次单字节调用；DRV8301 允许帧内任意间隙
3. **同名文件**：`code/adc.h`、`code/spi.h` 与 `Core/Inc/` 同名，`headline.h`
   按名 include 命中 code/ 那份，句柄 extern 在 code 层自己声明
4. **clangd 幽灵诊断**：会报已删文件（app_main.c 等）与编辑竞态假错，
   先查磁盘再信

## 四、下一步（按优先级）

### 1. ADC 采样层（`code/adc.c/h`，不需要电机）——2026-11-24 已完成

上电验证通过（判据与结果见第五节），以下配置说明保留备查。

CubeMX 已配好（`Core/Src/adc.c`）：

- **规则组（ADC1，软件触发）**：VBUS = PC2(CH8)、NTC1 = PB0(CH15)、
  NTC2 = PB1(CH12)、VREFINT；`ADC_MODE_INDEPENDENT`（非双 ADC 同步），
  可直接 `HAL_ADC_Start` + 轮询读
- **注入组**：ADC1 = PA0/PA1（CH1/CH2），触发 T8_TRGO2；ADC2 = PC0/PC1，
  触发 T1_TRGO2（设计 3.2 第 9 条；ADC2 段生成代码尚未逐行核对）。
  **软件置 JADSTART 可直接启动一次**，自检不需要 TIM 运行

要做的：

- `adc_vbus_read()`：VBUS raw → VREFINT 反推 VDDA（`3.000 × CAL / meas`）→
  `V_bus = V_adc × (240 + 33) / 33`（实物分压 240k/33k）
- `adc_phase_offset_read()`：四路 SO 原始码，期望 ≈2048（用户要求用软件
  替代万用表，上电自检打印）
- `adc_dc_cal()`：拉 PB10 → 读 → 拉低
- 判据：VBUS ≈ 限流源设定值；SO raw ≈ 2048 ±100；DRV Status1/2 无故障位

### 2. TIM 启动 + 注入组定时触发（阶段 2 前置）
