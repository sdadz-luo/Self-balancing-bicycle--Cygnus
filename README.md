# 天鹅座（Cygnus）自平衡自行车

无人自主平台的自平衡自行车，由 STM32G431 电驱、ESP32-S3 下位机与 RDK X5
决策端构成控制系统，另配 STM32F103 遥控器作为按需上电的手动手段。
验收分三层递进：静止平衡 → 行驶与转向 → 陌生园区自主导航。
