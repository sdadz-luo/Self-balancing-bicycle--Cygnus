# esp32s3-control —— 下位机（ESP32-S3）

控制域主控固件：平衡环、运动控制、状态机、指令仲裁。
IMU（HWT606）直挂本地，经 CAN 与电驱板、RDK X5 通信。

- 硬件：ESP32-S3 + 外接 CAN 收发器，图纸见
  [hardware/control-board](../hardware/control-board/)
- 工具链：ESP-IDF
- 板级设计与固件架构：[下位机设计方案](../docs/天鹅座-ESP32S3_下位机设计方案.md)
- 文档：[参数与配置·四、ESP32-S3 下位机](../docs/天鹅座-参数与配置.md)
- 构建方式与改动禁区见 [CLAUDE.md](CLAUDE.md)

## 功能

| 职责 | 要点 |
| --- | --- |
| 上电自检 | IMU 数据有效 + CAN 收到电驱状态帧 + 舵机应答；不通过先重试，**3 次失败蜂鸣器报警** |
| 平衡环 | 起步 200 Hz → 目标 500 Hz（2 ms）；陀螺角速度内环 + 角度外环 → 动量轮力矩；飞轮转速进状态反馈（动量卸载） |
| 运动控制 | 速度环（摩擦驱动）+ 转向环（总线舵机）；动量轮 ↔ 转向权重随车速连续调度；**无指令时速度环目标为 0**（原地平衡、不移动） |
| 状态机 | 起立 / 正常 / 分级降级（可恢复 · 饱和 · 软停车 · 认输）/ 停机 |
| 指令仲裁 | RDK 建议（20 ~ 50 Hz）+ 遥控 + 急停（CAN **0x001**），进环前斜坡限幅 |
| 失效保护 | RDK 断链 > 200 ms 转入平衡 / 缓停；失稳最后一级是「认输」（车上无自动接住装置） |
| 黑匣子 | 30 s × 500 Hz 环形缓冲（PSRAM ~480 KB），按需经调试串口或 RDK 导出 |
| 无线调试 | **调试期**开 WiFi AP（遥测抽帧 + 在线调参），**运行期关闭**；与遥控的射频共存配置见[参数 4.8](../docs/天鹅座-参数与配置.md) |

## 要接的设备

| 设备 | 接口 | 配置 | 备注 |
| --- | --- | --- | --- |
| IMU（维特 HWT606） | UART1 | 921600 | 500 Hz 回传；上电第一件事改 `BANDWIDTH` 到 256 Hz |
| 总线舵机（飞特 ST-3035-C001） | UART2 | 500 k 或 115200 | 半双工 TTL；命令 ≥ 50 Hz；**1 Mbps 是上限，别顶格** |
| CAN 收发器（**须 3.3 V 型号**） | TWAI | 500 kbps | 连电驱板与 RDK；经典 CAN，不用 FD |
| 遥控接收（NRF24L01+PA+LNA） | SPI | — | 必须开自动应答（EN_AA 通道 0）；**供电轨按模块版本**——带板载 LDO 的接 5 V，不带的接 3.3 V |
| 调试 / 烧录（串口） | UART0 | 115200 | 兼 ROM 下载口 |
| 烧录 / 调试（USB） | USB-Serial-JTAG | — | **Type-C 座**，D± = GPIO19/20；一线上烧录 + JTAG + 备用 console |
| 蜂鸣器 | GPIO47 | — | 「认输」档提示（三极管驱动） |
| 状态灯 | GPIO48 | — | 4G 信号指示（数据经 CAN 获取） |
| 供电 | — | 5 V 输入，本地降 3.3 V | 取电源板 5 V（非其 3.3 V 轨）；本地同步 Buck |

**3 路 UART 已用满**（UART0 日志 / UART1 IMU / UART2 舵机）——再加设备只能走
I2C 或 SPI，分配与引脚约束见[参数 4.7](../docs/天鹅座-参数与配置.md)。

**不接本端**：双目、激光雷达、GNSS 接 RDK X5；电机、编码器、DRV8301 归 STM32
电驱板。**控制域先启动、不等 RDK**——不接入 RDK 时全车仍可由遥控器完整控制。**超声波已从方案中移除**（2026-10）；**车轮霍尔**里程计的物理接口归属
未定（接本端转发或直连 RDK）。
