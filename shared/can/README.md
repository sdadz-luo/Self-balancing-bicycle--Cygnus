# shared/can —— CAN 协议契约

CAN 总线（STM32 / ESP32 / RDK 三端）共享的帧定义、ID 分配表与 DBC 文件。
**这里就是三端的接口契约**，改这里等于改三端；新增帧必须落入既有 ID 分配段
（安全 / 控制 / 电驱状态 / 规划 / 整车状态 / 保护）。

- 帧格式与 ID 分配：[参数与配置·4.5 CAN 总线配置](../../docs/天鹅座-参数与配置.md)
- 遥控器不直接上 CAN：NRF24L01 帧经 ESP32 转发，格式见
  [参数与配置·4.4 遥控链路](../../docs/天鹅座-参数与配置.md)
